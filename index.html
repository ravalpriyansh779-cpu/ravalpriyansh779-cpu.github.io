CampusLens

Multi-tenant RAG platform for institutional knowledge

AI / RAG

The problem

One application, many organizations. Each tenant must see only its own documents, and answers must be verifiable — never hallucinated.

What I built

  • Tenant-isolated ingestion pipeline: chunk → embed → upsert
  • Per-tenant Pinecone namespaces with JWT tenant claims
  • Repository-layer tenant enforcement; citation-grounded prompts

The result

  • Hard tenant isolation — no cross-tenant leakage possible
  • Answers grounded in cited source documents
  • SQL and vector store working in a single transaction flow

02

TaskForge

AI operations dashboard with a human-first permission model

Security / AI

The problem

An AI assistant embedded in a dashboard must never outrank its human user. Every agent action needs to be attributable, scoped, and reversible.

What I built

  • JWT authentication with refresh rotation and route-level authorization
  • Admin / Operator / Viewer permission matrix enforced server-side
  • Audit log for every agent tool-call, with environment-scoped secrets

The result

  • Zero permission escapes across all tested role combinations
  • 100% of agent actions traceable to an actor and timestamp
  • Containerized deployment — reproducible across environments

03

PulseBoard

Real-time collaborative Kanban with conflict resolution

Realtime

The problem

Multiple users editing the same board caused refresh conflicts and lost updates. Standard polling was too slow and too heavy.

What I built

  • Optimistic UI with last-write-wins conflict resolution
  • Board-scoped Socket.IO rooms for targeted event broadcast
  • RBAC schema with fractional card positioning for reorder stability

The result

  • Sub-second sync across distributed clients
  • Zero lost-update reports during testing
  • Drag-to-reorder remains stable under concurrent edits

  • TypeScript
  • Node.js
